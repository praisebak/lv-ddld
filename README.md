
# 댕댕로드
당신과 애견을 위한 스마트한 산책 관리 앱 [댕댕로드](https://lv-ddld.vercel.app/)입니다



## 페르소나 (유저 케이스)
### 🐶 페르소나 1: 초보 애견인 “지현” (29세, 신입 반려인)

- **배경 정보**  
  - 직장인, 반려견 입양 1개월 차  
  - 모든 게 낯설고 처음이라 실수도 잦음  
  - 퇴근 후 짧은 산책 시도 중

- **주요 행동 및 문제**  
  - 산책 전후 챙겨야 할 것 자주 까먹음  
  - 산책 주기와 시간에 대한 기준 부족  
  - 피곤하거나 귀찮으면 그냥 넘김

- **주요 니즈**  
  - 산책 루틴을 자동화하고 싶은 욕구  
  - 리마인더 기능과 "잘하고 있다"는 피드백 원함

- **디지털 성향**  
  - 앱 사용은 기본 수준, 복잡한 UI는 어려움  
  - 알림 기반의 간단한 UX 선호  

### 🔍 인수 조건 (Given-When-Then 형식)

- **Given** 사용자가 산책 알림 시간을 설정하고  
- **When** 설정된 시간 10분 전이 되면  
- **Then** 체크리스트 알림이 푸시 메시지로 도착한다

- **Given** 사용자가 기본 체크리스트를 커스터마이징한 경우  
- **When** 알림이 도착하면  
- **Then** 커스터마이징된 항목이 포함되어야 한다

- **Given** 알림을 클릭한 경우  
- **Then** 앱 내 ‘체크리스트 화면’으로 이동한다

### 📋 인수 조건 (체크리스트 형식)

- [ ] 산책 시간 10분 전에 알림이 온다  
- [ ] 알림 내용에 체크리스트 항목이 포함된다  
- [ ] 체크리스트는 사용자가 수정한 내용으로 반영된다  
- [ ] 알림 클릭 시 앱 내 관련 화면으로 이동된다

### 🐕 페르소나 2: 사회화를 원하는 중수 애견인 “태훈” (35세, 2년 차 반려인)

- **배경 정보**  
  - 반려견과 함께한지 2년째  
  - 사회성 기르기 위해 산책에 공들임  
  - 주말마다 새로운 장소를 찾으려 노력

- **주요 행동 및 문제**  
  - 위치 기반 커뮤니티나 후기를 검색함  
  - 강아지 성향에 맞는 장소를 찾기 어려움  
  - 산책 친구를 만들 기회 부족

- **주요 니즈**  
  - 강아지 성향 기반 장소 추천 (조용 vs 활기)  
  - 지금 거기에 다른 강아지들이 있는지 궁금  
  - 커뮤니티 연결도 원함

- **디지털 성향**  
  - SNS, 지도 기반 앱에 익숙  
  - 태그, 필터 기능에 친숙

---
### 🔍 인수 조건 (Given-When-Then 형식)

- **Given** 사용자가 자신의 강아지 성향(조용함/활발함)을 설정한 경우  
- **When** 산책 장소를 추천받을 때  
- **Then** 강아지 성향에 맞는 장소가 우선순위로 노출된다

- **Given** 추천 리스트에서 특정 장소를 클릭하면  
- **Then** 해당 장소의 현재 반려견 활동 정보(혼잡도, 성향 태그 등)가 표시된다

- **Given** 위치 기반 기능이 활성화된 경우  
- **Then** 사용자의 현재 위치 근처 장소가 추천된다

### 📋 인수 조건 (체크리스트 형식)

- [ ] 강아지 성향에 따라 장소 필터링이 가능하다  
- [ ] 장소 태그(‘활기참’, ‘조용함’, ‘사회화 추천’ 등)가 표시된다  
- [ ] 현재 반려견 수나 활동 정보가 시각화되어 제공된다  
- [ ] 위치 기반으로 근처 장소가 추천된다 

### 🏞 페르소나 3: 최근 이사한 애견인 “수빈” (32세, 프리랜서)

- **배경 정보**  
  - 최근 타지로 이사  
  - 동네 지리에 익숙하지 않아 불안  
  - 반려견은 소음에 예민함

- **주요 행동 및 문제**  
  - 항상 똑같은 길만 도는 산책  
  - 안전하고 조용한 산책로를 모르겠음  
  - 혼잡한 곳은 피하고 싶음

- **주요 니즈**  
  - 현재 위치 기반 조용한 산책로 추천  
  - 산책 중인 사람·반려견 수 시각화  
  - 리뷰 기반 안전 정보

- **디지털 성향**  
  - 지도 기능에 익숙  
  - 간결하고 신뢰할 수 있는 정보 선호

- **Given** 사용자가 위치 접근 권한을 허용한 경우  
- **When** ‘주변 산책로 탐색’ 기능을 실행하면  
- **Then** 조용한/활기찬 정도가 태그로 구분된 산책로 목록이 표시된다

- **Given** 사용자가 특정 산책로를 선택했을 때  
- **Then** 해당 산책로의 ‘최근 애견인 산책 인구 수’가 표시된다

### 📋 인수 조건 (체크리스트 형식)

- [ ] 사용자의 현재 위치 기반으로 산책로가 추천된다  
- [ ] 산책로 별 분위기(조용함/시끄러움) 태그가 존재한다  
- [ ] 최근 1시간 산책 인구 수를 확인할 수 있다  

## 페르소나 기반 추출 핵심 기능

### 1. **체크리스트 + 타이머 패턴** (초보자 친화적)

- 산책 전후 체크리스트와 산책 시간 측정
- 간단한 타이머와 알림 기능

### 2. **지도 + 실시간 정보 패턴** (위치 기반)

- 주변 산책로 표시와 실시간 주변 강아지 밀집도
- 조용한/시끄러운 지역 구분

### 3. **매칭 + 소셜 패턴** (커뮤니티 중심)

- 근처 강아지 프로필 매칭
- 실시간 만남 요청 기능

### 4. **AI 추천 + 개인화 패턴** (데이터 기반)

- 강아지 정보 기반 맞춤 추천
- 학습 기반 산책 플래너

### 5. **게임화 + 리워드 패턴** (동기부여 중심)

- 산책 포인트와 뱃지 시스템
- 도전과제와 레벨업
