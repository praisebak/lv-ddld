
# 댕댕로드
당신과 애견을 위한 스마트한 산책 관리 앱 [댕댕로드](https://lv-ddld.vercel.app/)입니다

## 페르소나 (유저 케이스)
### 🐶 페르소나 1: 초보 애견인 “지현” (29세, 신입 반려인)

- **배경 정보**  
  - 직장인, 반려견 입양 1개월 차  
  - 모든 게 낯설고 처음이라 실수도 잦음  
  - 퇴근 후 짧은 산책 시도 중

- **주요 행동 및 문제**  
  - 산책 전후 챙겨야 할 것 자주 까먹음  
  - 산책 주기와 시간에 대한 기준 부족  
  - 피곤하거나 귀찮으면 그냥 넘김

- **주요 니즈**  
  - 산책 루틴을 자동화하고 싶은 욕구  
  - 리마인더 기능과 "잘하고 있다"는 피드백 원함

- **디지털 성향**  
  - 앱 사용은 기본 수준, 복잡한 UI는 어려움  
  - 알림 기반의 간단한 UX 선호  

### 🔍 인수 조건 (Given-When-Then 형식)

- **Given** 사용자가 산책화면에 들어옴
- **When** 산책 시작 버튼을 누르면  
- **Then** 체크리스트를 확인한뒤 지도 화면이 출력되면서 산책을 시작할 수 있다

- **Given** 사용자가 기본 체크리스트를 커스터마이징한 경우  
- **When** 알림이 도착하면  
- **Then** 커스터마이징된 항목이 포함되어야 한다


### 📋 인수 조건 (체크리스트 형식)

- [ ] 산책 시작시 체크리스트가 출력된다
- [ ] 체크리스트는 사용자가 수정한 내용으로 반영된다  
- [ ] 체크리스트가 통과되면 산책 지도 화면이 출력된다.

### 🔍 인수 조건 (Given-When-Then 형식)

- **Given** 사용자가 자신의 강아지 성향(조용함/활발함)을 설정한 경우  
- **When** 산책 장소를 추천받을 때  
- **Then** 강아지 성향에 맞는 장소가 우선순위로 노출된다

- **Given** 산책장소 추천 화면에서
- **Then** 주변 장소의 혼잡도, 도심인지 자연인지 출력된다.

- **Given** 산책 지도 화면에서
- **Then** 주변 강아지들의 정보들이 출력된다

- **Given** 산책 지도 화면에서
- **When** 주변 강아지들 카드를 선택할 수 있다
- **Then** 상대방에게 알람이 간다


### 📋 인수 조건 (체크리스트 형식)
- [ ] 성향에 따라 장소 필터링이 가능하다  
- [ ] 장소 태그(‘활기참’, ‘조용함' 등)가 표시된다  
- [ ] 현재 반려견 수나 활동 정보가 시각화되어 제공된다  
- [ ] 위치 기반으로 근처 장소가 추천된다
- [ ] 도심인지 자연인지 출력한다.

- **디지털 성향**  
  - 지도 기능에 익숙  
  - 간결하고 신뢰할 수 있는 정보 선호

- **Given** 사용자가 위치 접근 권한을 허용한 경우  
- **When** ‘주변 산책로 탐색’ 기능을 실행하면  
- **Then** 조용한/활기찬 정도가 태그로 구분된 산책로 목록이 표시된다

- **Given** 사용자가 특정 산책로를 선택했을 때  
- **Then** 해당 산책로의 ‘최근 애견인 산책 인구 수’가 표시된다

- [ ] 최근 산책 인구 수를 확인할 수 있다  

## 페르소나 기반 추출 핵심 기능

### 1. **체크리스트 + 타이머 패턴** (초보자 친화적)

- 산책 전후 체크리스트와 산책 시간 측정
- 간단한 타이머와 알림 기능

### 2. **지도 + 실시간 정보 패턴** (위치 기반)

- 주변 산책로 표시와 실시간 주변 강아지 밀집도
- 조용한/시끄러운 지역 구분

### 3. **매칭 + 소셜 패턴** (커뮤니티 중심)

- 산책 지도 화면에서 근처 강아지 프로필 매칭
- 실시간 만남 요청 기능

### 4. **산책 스트릭** (데이터 기반)
- 강아지 산책 경과를 한눈에 확인하여 산책을 놓치지 않게 해준다

### 5. **게임화 + 리워드 패턴** (동기부여 중심)
- 산책 포인트와 뱃지 시스템
- 도전과제와 레벨업
